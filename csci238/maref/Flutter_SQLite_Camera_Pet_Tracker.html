Flutter: SQLite, Camera Integration, and Persistent Image Storage

Mobile applications frequently need to manage more than simple settings. An animal shelter, for example, needs to maintain records of animals entering its care, photograph those animals, document their adoption, and retain historical information. Such an application combines structured database records with files stored on the device.

This chapter develops a Humane Society Pet Tracker, a complete Flutter application that integrates SQLite, the device camera, the photo library, and a responsive user interface. It builds on familiarity with Dart classes, asynchronous programming, forms, navigation, and StatefulWidget.

1. Application architecture

The application supports animal intake, editing, photography, adoption information, archiving, and permanent record deletion. Each animal appears as a card in a grid. Selecting a card opens an editing form; the floating action button opens an empty intake form.

Four components cooperate to provide this functionality:

Component Responsibility
Pet Represents an individual animal and converts between Dart objects and database rows.
DatabaseHelper Opens the database and implements database operations.
PetGridScreen Displays active or archived animals in a responsive grid.
PetFormScreen Collects and validates information, captures photographs, and saves records.

The database and file system serve different purposes. SQLite stores structured information such as names, dates, and adoption status. The file system stores photographs. A database field named imagePath connects each record to its photograph.

PetFormScreen
    |-- animal information --> DatabaseHelper --> SQLite pets table
    |-- camera/gallery --> image_picker --> application documents directory
    |                                           |
    |---------------- imagePath ----------------+

PetGridScreen <-- Pet objects <-- DatabaseHelper
    |-- imagePath --> Image.file() --> photograph

This separation allows the application to query animal records without retrieving large binary photographs in every database result. SQLite can store binary data using the BLOB storage class, and doing so is appropriate in some applications. For this project, separate files simplify image display and keep ordinary record queries small. The trade-off is that the application must manage the relationship between files and records.

2. Creating the Flutter project

Create a project from a terminal and install its dependencies:

flutter create humane_society_tracker
cd humane_society_tracker
flutter pub add sqflite path path_provider image_picker
Package Purpose
sqflite Provides access to a local SQLite database.
path Constructs and manipulates file paths.
path_provider Locates platform-appropriate application directories.
image_picker Opens the system camera or photo selection interface.

The installation command updates pubspec.yaml and resolves compatible dependency versions. The example targets Android and iOS; it uses dart:io and is not a Flutter web implementation.

Platform configuration

On Android, image_picker normally uses the system camera and photo selection interfaces without additional manifest configuration. If your application independently declares camera permission, it must also handle the applicable permission requirements; do not add permissions merely to troubleshoot an unrelated camera error.

On iOS, open ios/Runner/Info.plist and include these entries within the existing top-level <dict>:

<key>NSCameraUsageDescription</key>
<string>We need camera access to photograph intake pets.</string>
<key>NSPhotoLibraryUsageDescription</key>
<string>We need photo library access to select existing pet photos.</string>

These strings explain why the application requests access. Preserve the existing configuration. Building the iOS version requires an appropriate macOS and Xcode environment.

3. Modeling animal records

The Pet class represents a row in the pets table. Its nullable id distinguishes a new object, whose identifier has not yet been assigned by SQLite, from an existing record.

Field SQLite storage Description
id INTEGER Automatically generated primary key.
name TEXT Required animal name.
category TEXT Dog or Cat.
breed TEXT Breed description.
approxAge TEXT Approximate age, such as 2 yrs.
intakeDate TEXT Date of arrival.
adoptionDate TEXT Date of adoption, if known.
adopterName TEXT Name of adopter.
adopterAddress TEXT Address of adopter.
comments TEXT Medical, behavioral, or other notes.
imagePath TEXT Location of the stored photograph.
isArchived INTEGER 0 for active records, 1 for archived records.

SQLite does not have a separate Boolean storage class. The example represents Boolean status using integers. Dates are stored as text in YYYY-MM-DD format; the sample permits manual entry and does not enforce date validity. Approximate age is also text, making values such as 6 months easy to enter but less convenient for numeric sorting.

Mapping objects to database rows

The toMap() method converts a Dart object into a Map<String, dynamic> whose keys match the database columns. The Pet.fromMap() factory constructor performs the reverse operation. This mapping keeps SQL-related details separate from the widgets that display animal information.

4. Database operations and archiving

DatabaseHelper uses the singleton pattern to provide a shared helper instance. Its database getter opens the database when needed and retains the resulting handle. The onCreate callback creates the table when a new database is initialized. The database version is set to 1; future schema changes would require a migration strategy.

CRUD describes the four fundamental database operations:

Operation Method Result
Create insertPet() Adds an animal record.
Read getPets() Retrieves active or archived records.
Update updatePet() Modifies an existing record.
Delete deletePet() Permanently removes a database row.

The read operation uses a parameterized filter:

where: 'isArchived = ?',
whereArgs: [showArchived ? 1 : 0],
orderBy: 'id DESC',

The placeholder ? is supplied through whereArgs rather than constructing SQL through string concatenation. The query returns the selected status group, with the highest identifiers first.

Archiving is an update, not a deletion. Setting isArchived to 1 removes an animal from the active view while retaining its information. An archived record can be opened and restored by turning off its archive switch and saving it again. The permanent delete operation, by contrast, removes the row after confirmation.

5. Camera integration and image storage

Flutter provides several approaches to camera integration. The camera package offers direct control over camera previews and capture sessions, but requires additional lifecycle and controller management. For an application that simply needs to acquire a photograph, image_picker is a simpler choice.

The form calls the same method with either ImageSource.camera or ImageSource.gallery. If the user cancels the picker, the returned value is null and the existing photo remains unchanged.

Camera captures may reside in temporary cache storage. Saving a temporary path to the database does not ensure that the photograph will remain available. The application therefore copies the selected file into its application documents directory before recording its path.

final appDir = await getApplicationDocumentsDirectory();
final fileName = 'pet_${DateTime.now().millisecondsSinceEpoch}${p.extension(pickedFile.path)}';
final permanentPath = p.join(appDir.path, fileName);
final savedImage = await File(pickedFile.path).copy(permanentPath);

The timestamp helps distinguish file names, although it is not a strict uniqueness guarantee. The picker requests a maximum width of 1000 pixels and an image quality of 85 to reduce storage and decoding costs where supported. Application documents storage persists across ordinary restarts, but it is not a backup and may be removed when application data is cleared or the app is uninstalled.

6. Responsive grids and data-entry forms

A fixed two-column grid may work on a phone but waste space on a tablet. The example uses MediaQuery to obtain the available screen width and calculates a column count:

final screenWidth = MediaQuery.of(context).size.width;
final crossAxisCount = (screenWidth / 180).floor().clamp(2, 5);
Screen width (logical pixels) Columns
390 2
600 3
800 4
900 5

The actual card width also depends on padding and spacing. GridView.builder creates cards as needed. Each card displays the animal photograph, name, age, and intake date. If a photograph is absent or its file no longer exists, an icon is displayed instead.

The form uses a GlobalKey<FormState> to validate input, TextEditingController objects to manage editable text, a dropdown to select the animal category, date pickers to populate date fields, and a switch to control archived status. The same form supports creation and editing: a null pet argument represents a new intake, while an existing Pet supplies initial values.

When saving, the form validates the required name, constructs a Pet object, chooses insertion or update, and returns to the grid using Navigator.pop(). The grid then queries SQLite again to reflect the changes.

class Pet {
  final int? id;
  final String name;
  final String category; // 'Dog' or 'Cat'
  final String breed;
  final String approxAge;
  final String intakeDate;
  final String adoptionDate;
  final String adopterName;
  final String adopterAddress;
  final String comments;
  final String imagePath;
  final int isArchived; // SQLite lacks a boolean type; 0 = Active, 1 = Archived

  Pet({
    this.id,
    required this.name,
    required this.category,
    required this.breed,
    required this.approxAge,
    required this.intakeDate,
    this.adoptionDate = '',
    this.adopterName = '',
    this.adopterAddress = '',
    this.comments = '',
    this.imagePath = '',
    this.isArchived = 0,
  });

  // Convert a Pet object into a Map for sqflite insertion
  Map<String, dynamic> toMap() {
    return {
      'id': id,
      'name': name,
      'category': category,
      'breed': breed,
      'approxAge': approxAge,
      'intakeDate': intakeDate,
      'adoptionDate': adoptionDate,
      'adopterName': adopterName,
      'adopterAddress': adopterAddress,
      'comments': comments,
      'imagePath': imagePath,
      'isArchived': isArchived,
    };
  }

  // Extract a Pet object from a sqflite Map row
  factory Pet.fromMap(Map<String, dynamic> map) {
    return Pet(
      id: map['id'] as int?,
      name: map['name'] as String? ?? '',
      category: map['category'] as String? ?? 'Dog',
      breed: map['breed'] as String? ?? '',
      approxAge: map['approxAge'] as String? ?? '',
      intakeDate: map['intakeDate'] as String? ?? '',
      adoptionDate: map['adoptionDate'] as String? ?? '',
      adopterName: map['adopterName'] as String? ?? '',
      adopterAddress: map['adopterAddress'] as String? ?? '',
      comments: map['comments'] as String? ?? '',
      imagePath: map['imagePath'] as String? ?? '',
      isArchived: map['isArchived'] as int? ?? 0,
    );
  }
}

// 2. DATABASE HELPER (Singleton Pattern)
// ============================================================================

class DatabaseHelper {
  static final DatabaseHelper instance = DatabaseHelper._init();
  static Database? _database;

  DatabaseHelper._init();

  Future<Database> get database async {
    if (_database != null) return _database!;
    _database = await _initDB('humane_society.db');
    return _database!;
  }

  Future<Database> _initDB(String filePath) async {
    final dbPath = await getDatabasesPath();
    final path = p.join(dbPath, filePath);

    return await openDatabase(
      path,
      version: 1,
      onCreate: _createDB,
    );
  }

  Future<void> _createDB(Database db, int version) async {
    await db.execute('''
      CREATE TABLE pets (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        name TEXT NOT NULL,
        category TEXT NOT NULL,
        breed TEXT,
        approxAge TEXT,
        intakeDate TEXT,
        adoptionDate TEXT,
        adopterName TEXT,
        adopterAddress TEXT,
        comments TEXT,
        imagePath TEXT,
        isArchived INTEGER NOT NULL DEFAULT 0
      )
    ''');
  }

  // CREATE
  Future<int> insertPet(Pet pet) async {
    final db = await instance.database;
    return await db.insert('pets', pet.toMap());
  }

  // READ (Filtered by active vs. archived status)
  Future<List<Pet>> getPets({required bool showArchived}) async {
    final db = await instance.database;
    final result = await db.query(
      'pets',
      where: 'isArchived = ?',
      whereArgs: [showArchived ? 1 : 0],
      orderBy: 'id DESC',
    );
    return result.map((map) => Pet.fromMap(map)).toList();
  }

  // UPDATE (Used for both general edits and toggling the archive flag)
  Future<int> updatePet(Pet pet) async {
    final db = await instance.database;
    return await db.update(
      'pets',
      pet.toMap(),
      where: 'id = ?',
      whereArgs: [pet.id],
    );
  }

  // DELETE
  Future<int> deletePet(int id) async {
    final db = await instance.database;
    return await db.delete(
      'pets',
      where: 'id = ?',
      whereArgs: [id],
    );
  }
}

class PetGridScreen extends StatefulWidget {
  const PetGridScreen({super.key});

  @override
  State<PetGridScreen> createState() => _PetGridScreenState();
}

class _PetGridScreenState extends State<PetGridScreen> {
  List<Pet> _pets = [];
  bool _showArchived = false;
  bool _isLoading = true;

  @override
  void initState() {
    super.initState();
    _refreshPets();
  }

  // Fetch updated records from SQLite and rebuild the UI
  Future<void> _refreshPets() async {
    setState(() => _isLoading = true);
    final data = await DatabaseHelper.instance.getPets(showArchived: _showArchived);
    setState(() {
      _pets = data;
      _isLoading = false;
    });
  }

  @override
  Widget build(BuildContext context) {
    // MediaQuery determines screen width to dynamically adjust column count
    final screenWidth = MediaQuery.of(context).size.width;
    
    // Divide screen width by ~180px per card, clamping between 2 and 5 columns
    final crossAxisCount = (screenWidth / 180).floor().clamp(2, 5);

    return Scaffold(
      appBar: AppBar(
        title: Text(_showArchived ? 'Archived Pets' : 'Humane Society Pets'),
        actions: [
          // Filter toggle between Active (0) and Archived (1) records
          Row(
            children: [
              const Text('Archived', style: TextStyle(fontSize: 14)),
              Switch(
                value: _showArchived,
                onChanged: (val) {
                  setState(() => _showArchived = val);
                  _refreshPets();
                },
              ),
            ],
          ),
        ],
      ),
      body: _isLoading
          ? const Center(child: CircularProgressIndicator())
          : _pets.isEmpty
              ? Center(
                  child: Text(
                    _showArchived
                        ? 'No archived pets found.'
                        : 'No active pets. Tap + to intake a pet!',
                  ),
                )
              : GridView.builder(
                  padding: const EdgeInsets.all(12),
                  gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
                    crossAxisCount: crossAxisCount,
                    crossAxisSpacing: 12,
                    mainAxisSpacing: 12,
                    childAspectRatio: 0.78, // Controls height-to-width ratio of cards
                  ),
                  itemCount: _pets.length,
                  itemBuilder: (context, index) {
                    final pet = _pets[index];
                    return _buildPetCard(pet);
                  },
                ),
      floatingActionButton: FloatingActionButton(
        onPressed: () async {
          // Navigate to empty form for adding a new pet
          await Navigator.push(
            context,
            MaterialPageRoute(builder: (context) => const PetFormScreen()),
          );
          _refreshPets();
        },
        child: const Icon(Icons.add),
      ),
    );
  }

  Widget _buildPetCard(Pet pet) {
    final hasValidImage = pet.imagePath.isNotEmpty && File(pet.imagePath).existsSync();

    return Card(
      clipBehavior: Clip.antiAlias,
      elevation: 3,
      child: InkWell(
        onTap: () async {
          // Navigate to populated form for editing/archiving/deleting
          await Navigator.push(
            context,
            MaterialPageRoute(builder: (context) => PetFormScreen(pet: pet)),
          );
          _refreshPets();
        },
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.stretch,
          children: [
            // Pet Thumbnail Image
            Expanded(
              child: hasValidImage
                  ? Image.file(
                      File(pet.imagePath),
                      fit: BoxFit.cover,
                    )
                  : Container(
                      color: Colors.teal.shade50,
                      child: Icon(
                        pet.category == 'Cat' ? Icons.cruelty_free : Icons.pets,
                        size: 56,
                        color: Colors.teal.shade300,
                      ),
                    ),
            ),
            // Required Summary Info: Name, Age, Intake Date
            Padding(
              padding: const EdgeInsets.all(8.0),
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.start,
                children: [
                  Text(
                    pet.name,
                    style: const TextStyle(fontWeight: FontWeight.bold, fontSize: 16),
                    maxLines: 1,
                    overflow: TextOverflow.ellipsis,
                  ),
                  const SizedBox(height: 2),
                  Text(
                    'Age: ${pet.approxAge.isEmpty ? "N/A" : pet.approxAge}',
                    style: const TextStyle(fontSize: 13),
                    maxLines: 1,
                  ),
                  Text(
                    'Intake: ${pet.intakeDate.isEmpty ? "N/A" : pet.intakeDate}',
                    style: TextStyle(fontSize: 12, color: Colors.grey.shade700),
                    maxLines: 1,
                  ),
                ],
              ),
            ),
          ],
        ),
      ),
    );
  }
}

// 4. FORM SCREEN: ADD, EDIT, ARCHIVE, DELETE & CAMERA CAPTURE

class PetFormScreen extends StatefulWidget {
  final Pet? pet; // Null if adding a new pet; populated if editing

  const PetFormScreen({super.key, this.pet});

  @override
  State<PetFormScreen> createState() => _PetFormScreenState();
}

class _PetFormScreenState extends State<PetFormScreen> {
  final _formKey = GlobalKey<FormState>();

  // Text Controllers for form fields
  late TextEditingController _nameCtrl;
  late TextEditingController _breedCtrl;
  late TextEditingController _ageCtrl;
  late TextEditingController _intakeDateCtrl;
  late TextEditingController _adoptionDateCtrl;
  late TextEditingController _adopterNameCtrl;
  late TextEditingController _adopterAddressCtrl;
  late TextEditingController _commentsCtrl;

  String _category = 'Dog';
  String _imagePath = '';
  bool _isArchived = false;

  @override
  void initState() {
    super.initState();
    final p = widget.pet;
    _nameCtrl = TextEditingController(text: p?.name ?? '');
    _category = p?.category ?? 'Dog';
    _breedCtrl = TextEditingController(text: p?.breed ?? '');
    _ageCtrl = TextEditingController(text: p?.approxAge ?? '');
    
    // Default intake date to today (YYYY-MM-DD) for new entries
    final today = DateTime.now().toIso8601String().split('T').first;
    _intakeDateCtrl = TextEditingController(text: p?.intakeDate ?? today);
    
    _adoptionDateCtrl = TextEditingController(text: p?.adoptionDate ?? '');
    _adopterNameCtrl = TextEditingController(text: p?.adopterName ?? '');
    _adopterAddressCtrl = TextEditingController(text: p?.adopterAddress ?? '');
    _commentsCtrl = TextEditingController(text: p?.comments ?? '');
    _imagePath = p?.imagePath ?? '';
    _isArchived = (p?.isArchived ?? 0) == 1;
  }

  @override
  void dispose() {
    // Always dispose controllers to prevent memory leaks
    _nameCtrl.dispose();
    _breedCtrl.dispose();
    _ageCtrl.dispose();
    _intakeDateCtrl.dispose();
    _adoptionDateCtrl.dispose();
    _adopterNameCtrl.dispose();
    _adopterAddressCtrl.dispose();
    _commentsCtrl.dispose();
    super.dispose();
  }

  // Launches the device camera or photo gallery and copies the image to permanent storage
  Future<void> _captureImage(ImageSource source) async {
    final picker = ImagePicker();
    final pickedFile = await picker.pickImage(
      source: source,
      maxWidth: 1000, // Downscale large camera photos to save storage and RAM
      imageQuality: 85,
    );

    if (pickedFile != null) {
      // pickedFile.path is stored in a temporary OS cache that gets cleared periodically.
      // We must copy the file into the app's permanent Document Directory.
      final appDir = await getApplicationDocumentsDirectory();
      final fileName = 'pet_${DateTime.now().millisecondsSinceEpoch}${p.extension(pickedFile.path)}';
      final permanentPath = p.join(appDir.path, fileName);

      final savedImage = await File(pickedFile.path).copy(permanentPath);

      setState(() {
        _imagePath = savedImage.path;
      });
    }
  }

  // Helper method to populate date fields using Flutter's native DatePicker
  Future<void> _selectDate(TextEditingController controller) async {
    final picked = await showDatePicker(
      context: context,
      initialDate: DateTime.now(),
      firstDate: DateTime(2000),
      lastDate: DateTime(2100),
    );
    if (picked != null) {
      controller.text = picked.toIso8601String().split('T').first;
    }
  }

  Future<void> _savePet() async {
    if (!_formKey.currentState!.validate()) return;

    final petData = Pet(
      id: widget.pet?.id,
      name: _nameCtrl.text.trim(),
      category: _category,
      breed: _breedCtrl.text.trim(),
      approxAge: _ageCtrl.text.trim(),
      intakeDate: _intakeDateCtrl.text.trim(),
      adoptionDate: _adoptionDateCtrl.text.trim(),
      adopterName: _adopterNameCtrl.text.trim(),
      adopterAddress: _adopterAddressCtrl.text.trim(),
      comments: _commentsCtrl.text.trim(),
      imagePath: _imagePath,
      isArchived: _isArchived ? 1 : 0,
    );

    if (widget.pet == null) {
      await DatabaseHelper.instance.insertPet(petData);
    } else {
      await DatabaseHelper.instance.updatePet(petData);
    }

    if (mounted) Navigator.pop(context);
  }

  Future<void> _deletePet() async {
    if (widget.pet?.id == null) return;

    final confirm = await showDialog<bool>(
      context: context,
      builder: (ctx) => AlertDialog(
        title: const Text('Delete Record?'),
        content: Text('Permanently delete ${widget.pet!.name}? This cannot be undone.'),
        actions: [
          TextButton(onPressed: () => Navigator.pop(ctx, false), child: const Text('Cancel')),
          TextButton(
            onPressed: () => Navigator.pop(ctx, true),
            child: const Text('Delete', style: TextStyle(color: Colors.red)),
          ),
        ],
      ),
    );

    if (confirm == true) {
      await DatabaseHelper.instance.deletePet(widget.pet!.id!);
      if (mounted) Navigator.pop(context);
    }
  }

  @override
  Widget build(BuildContext context) {
    final isEditing = widget.pet != null;
    final hasValidImage = _imagePath.isNotEmpty && File(_imagePath).existsSync();

    return Scaffold(
      appBar: AppBar(
        title: Text(isEditing ? 'Edit Pet Record' : 'New Pet Intake'),
        actions: [
          if (isEditing)
            IconButton(
              icon: const Icon(Icons.delete_outline, color: Colors.red),
              tooltip: 'Delete Pet',
              onPressed: _deletePet,
            ),
        ],
      ),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(16),
        child: Form(
          key: _formKey,
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              // 1. IMAGE PREVIEW & CAMERA CONTROLS
              Container(
                height: 220,
                decoration: BoxDecoration(
                  color: Colors.grey.shade200,
                  borderRadius: BorderRadius.circular(12),
                  border: Border.all(color: Colors.grey.shade400),
                ),
                clipBehavior: Clip.antiAlias,
                child: hasValidImage
                    ? Image.file(File(_imagePath), fit: BoxFit.cover)
                    : const Center(
                        child: Text('No Photo Taken', style: TextStyle(color: Colors.grey)),
                      ),
              ),
              const SizedBox(height: 8),
              Row(
                mainAxisAlignment: MainAxisAlignment.spaceEvenly,
                children: [
                  ElevatedButton.icon(
                    onPressed: () => _captureImage(ImageSource.camera),
                    icon: const Icon(Icons.camera_alt),
                    label: const Text('Take Photo'),
                  ),
                  OutlinedButton.icon(
                    onPressed: () => _captureImage(ImageSource.gallery),
                    icon: const Icon(Icons.photo_library),
                    label: const Text('Gallery'),
                  ),
                ],
              ),
              const Divider(height: 32),

              // 2. CORE ANIMAL DETAILS
              TextFormField(
                controller: _nameCtrl,
                decoration: const InputDecoration(
                  labelText: 'Pet Name *',
                  border: OutlineInputBorder(),
                ),
                validator: (val) => (val == null || val.trim().isEmpty) ? 'Name is required' : null,
              ),
              const SizedBox(height: 12),
              Row(
                children: [
                  Expanded(
                    child: DropdownButtonFormField<String>(
                      value: _category,
                      decoration: const InputDecoration(
                        labelText: 'Category',
                        border: OutlineInputBorder(),
                      ),
                      items: const [
                        DropdownMenuItem(value: 'Dog', child: Text('Dog')),
                        DropdownMenuItem(value: 'Cat', child: Text('Cat')),
                      ],
                      onChanged: (val) => setState(() => _category = val!),
                    ),
                  ),
                  const SizedBox(width: 12),
                  Expanded(
                    child: TextFormField(
                      controller: _ageCtrl,
                      decoration: const InputDecoration(
                        labelText: 'Approx. Age',

8. Understanding the application lifecycle

WidgetsFlutterBinding.ensureInitialized() initializes Flutter’s bindings before the application starts. The grid loads database records through initState() and displays a progress indicator during the asynchronous query. Each time the archive filter changes or a form closes, _refreshPets() retrieves records and calls setState() to rebuild the interface.

The form initializes controllers using either existing values or defaults. When the form is removed, dispose() releases those controllers. The save method awaits the database operation before leaving the screen, and the mounted check prevents navigation through a disposed widget in that method.

The photograph is copied when selected, before the animal record is saved. This means canceling a form, replacing a photograph, or deleting a database row can leave an unused image file behind. The sample deliberately does not implement file cleanup. In addition, some asynchronous callbacks lack mounted checks, and database and picker failures do not yet have comprehensive error handling. These are useful areas for extending the implementation.

Start an Android emulator, iOS simulator, or connect a supported physical device. From the project directory, execute:

10. Design limitations and production considerations

This application illustrates local CRUD and device integration rather than a complete shelter management system. A production application would need stronger validation, error handling, safe file cleanup, database migrations, and a backup strategy. Absolute image paths can become invalid if the application storage location changes; storing relative file identifiers and resolving them against the current documents directory is another design option.

Adopter names and addresses are personal information. A real deployment should consider access controls, encryption where appropriate, retention policies, and secure backups. Ordinary local SQLite storage alone does not provide these safeguards.

11. Chapter summary

SQLite provides structured persistent storage, while the file system provides a natural location for photographs. A data model maps Dart objects to database rows, a database helper encapsulates CRUD operations, and Flutter widgets display and edit the records. Archiving preserves historical information through a status flag rather than deleting rows. By combining image_picker, path_provider, sqflite, and responsive layouts, the application demonstrates how several independent Flutter capabilities can be integrated into a single working design.

12. End-of-chapter exercises

Exercise 1: Search and filter

Add a search field to the grid that filters animals by name. Extend it to support filtering by category while retaining the active/archived filter.

Exercise 2: Validate adoption information

Require a valid adoption date and adopter name whenever a record is marked as adopted. Prevent adoption dates earlier than the intake date. Decide how adoption status should relate to archival status.

Exercise 3: Manage image files

Extend the application to remove obsolete photographs when an animal’s image is replaced or its record is permanently deleted. Consider what should happen when a user selects an image but cancels the form, and when a database operation fails. Avoid deleting a file still referenced by another record.

Exercise 4: Refactor the project

Move Pet, DatabaseHelper, PetGridScreen, and PetFormScreen into separate Dart files. Preserve all application behavior and verify persistence after restarting the application.
